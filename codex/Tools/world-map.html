How this works

Reading. Every .md in World/Locations/ becomes a node, grouped by region: and joined by connections:. Region names and colours come from World/Regions.md.

Moving. Drag a node to reposition it, then Save - that writes map_x: / map_y: into the file and pins it there while everything else keeps auto-arranging. Re-arrange clears every pin. This is the roadmap's upgrade path: the same fields would pin these nodes onto drawn map art later.

Connecting. Drag one node on top of another and a menu asks how to route them - both ways, or one-way in either direction. Both files get the connections: entry. Remove a route with the × on any connection chip in the sidebar, or add a missing return route with ↩.

Regions. Click a region's tinted area or its label to rename it or change its colour. Renaming rewrites region: in every location inside it. Colour is one hex per region, stored in World/Regions.md - the map derives a readable fill, border and label from it for both dark and light themes, so you only ever pick one value. A region with no colour set gets a stable automatic one derived from its name.

Unwritten places. A connections: entry naming a place with no file shows as a dashed ghost node. Select it and press Create this location to make a real seed file, in the right region and already linked back.

Factions and characters in the sidebar open a small card in place rather than navigating away, so you never lose your position on the map.

Nothing is stored in the browser except the pointer to your folder and your theme - the same two things the other tools remember. Everything else lives in the files.
