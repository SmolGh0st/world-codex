About this timeline

Three sources, all read directly off disk - nothing is stored anywhere but the files:

  • Events - one file per Events/*.md, grouped by its era: field and ordered within that era by any number found in its date: text.
  • Story placements - any Stories/*.md with timeline_position: set, ordered the same way. One with branched_from: set (written automatically by manuscript.html's ⑂ Branch button) shows which story it forks from and where - it also inherits that story's timeline_position:, which is why a branch lands right next to its parent instead of somewhere unrelated.
  • Lifespans - any Characters/*.md with born: and/or died: set.

Era order and colour come from World/Calendar.md - an era not listed there still works, it just sorts after the listed ones and gets an automatic colour.

This is a first draft: read-only. Write events and lifespans in the writer for now; editing straight from this page is a planned upgrade, same as the world map got.
